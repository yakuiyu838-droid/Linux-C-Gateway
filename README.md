# 基于 Linux 的高并发智能家居网关

## 📖 项目简介
本项目是一个基于纯 C 语言与 Linux 系统调用开发的智能家居网关。采用 `epoll` 单线程事件驱动模型，结合线程池、SQLite、自定义二进制协议，实现了从硬件串口采集、数据持久化，到网络查询与主动推送的完整物联网闭环。

## ✨ 核心特性
- **高并发架构**：采用 `epoll` (ET模式) 统一管理串口、网络与定时器 (`timerfd`)。
- **协议解析**：自定义“定长头+变长体+校验和”的二进制帧协议，彻底解决 TCP 粘包/半包问题。
- **异步解耦**：手写基于互斥锁与条件变量的线程池，将耗时的数据库查询与主 I/O 线程解耦。
- **周期推送**：基于 `timerfd` 实现客户端订阅功能，定时主动推送最新传感器数据。
- **优雅停机**：捕获 `SIGINT`/`SIGPIPE`，退出时安全释放线程池与数据库资源。

## 🛠️ 技术栈
`C` / `Linux` / `epoll` / `线程池` / `SQLite` / `cJSON` / `termios` / `Makefile`

## 🚀 编译与运行
1. 编译：`make`
2. 一键启动测试环境：`./run.sh`
3. 运行客户端测试：`./client`
